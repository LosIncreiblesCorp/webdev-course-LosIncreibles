# Guion de la Lección 1: ¿Qué es el Desarrollo Web? Introducción a HTML y CSS

## Detalles de la Lección

- **Duración aproximada:** 5 minutos
- **Público objetivo:** Estudiantes de secundaria (12 a 17 años).
- **Herramientas:** Navegador web y CodePen (100% en línea).
- **Lenguajes:** HTML y CSS.

---

## Estructura del Video

### Bloque 1: ¿Qué es el desarrollo web? (00:00 – 00:38)

- **[En pantalla]:** Mostrar diferentes sitios web conocidos, como YouTube, redes sociales y páginas de compras. Posteriormente, mostrar el título de la lección.
- **[Texto de apoyo visual]:** `¿Cómo se construye una página web?`
- **[Narración (Voz en off)]:**

> "Hola. Bienvenido a este curso. Seguro entras todos los días a páginas web para ver videos, hablar con tus amigos, buscar tareas o comprar algo. Pero, ¿alguna vez te preguntaste cómo se hace una página? ¿Quién decide dónde va cada texto, cada imagen y cada color?
>
> Pues alguien lo programó. Y en este curso vas a aprender a hacerlo tú. No necesitas saber nada de antes y tampoco necesitas instalar programas. Todo lo haremos desde tu navegador, el mismo que usas para ver este video. Empecemos a entender qué pasa cuando abres una página."

### Bloque 2: ¿Qué sucede cuando abrimos una página web? (00:38 – 01:16)

- **[En pantalla]:** Mostrar el proceso de acceso a una página web mediante un esquema animado: Usuario → Navegador → Servidor → Archivos → Página web.
- **[Texto de apoyo visual]:**
    - `Navegador: solicita la página.`
    - `Servidor: almacena y entrega archivos.`
    - `Archivos: contienen instrucciones.`
- **[Narración (Voz en off)]:**

> "Primero que nada, escribes una dirección, por ejemplo, la de YouTube y presionas Enter. Tu navegador, que puede ser Chrome, Firefox, Safari, entre otros, le pide a esa página a una computadora que está muy lejos, que se llama servidor.
>
> Un servidor es simplemente una computadora que guarda páginas y las entrega a quien las pide. El servidor responde enviando unos archivos de texto. Sí, de texto, como un documento. Y el navegador lee ese texto y entiende las instrucciones que tiene escritas."

### Bloque 3: HTML y CSS: Los dos lenguajes principales (01:16 – 01:54)

- **[En pantalla]:** Mostrar una página web y dividirla visualmente en dos partes: estructura y apariencia. Acompañar con la analogía de una casa.
- **[Texto de apoyo visual]:**
    - `HTML = Estructura y contenido`
    - `CSS = Estilos y apariencia`
    - `HTML + CSS = Página web`
- **[Narración (Voz en off)]:**

> "Y las convierte en una página que ves con colores, imágenes y botones. O sea, que toda la página web, por compleja que parezca, es en el fondo un archivo de texto con instrucciones y tú vas a aprender a escribirlas.
>
> Las instrucciones de una página se escriben con dos lenguajes principales.
>
> El primero se llama HTML y sirve para crear la estructura y el contenido. Los títulos, los párrafos, las imágenes, los enlaces, entre otros. Piensa en una casa. HTML son las paredes, las puertas y las ventanas.
>
> El segundo se llama CSS y sirve para darle estilo: los colores, el tipo y el tamaño de letra, el orden de las cosas. Siguiendo la comparación, CSS es la pintura y la decoración.
>
> Con HTML decides qué hay en la página y con CSS decides cómo se ve. En este curso aprenderás los dos y al final harás tu propia página de perfil."

### Bloque 4: Conociendo CodePen (01:54 – 03:14)

- **[En pantalla]:** Mostrar la página principal de CodePen y posteriormente abrir un proyecto (Pen). Señalar los paneles de HTML, CSS, JavaScript y la vista previa.
- **[Texto de apoyo visual]:**
    - `CodePen = Editor de código en línea`
    - `HTML → Estructura`
    - `CSS → Diseño`
    - `JavaScript → No lo utilizaremos por ahora`
    - `Vista previa → Resultado de nuestro código`
- **[Narración (Voz en off)]:**

> "Para escribir código necesitamos un lugar donde hacerlo y nosotros usaremos CodePen. CodePen es un editor en línea, es decir, una página web donde puedes escribir código HTML y CSS y ver el resultado al instante sin instalar nada.
>
> Cada proyecto de CodePen se llama Pen. Mira cómo está organizado.
>
> Arriba hay tres paneles. El primero es el panel de HTML, donde escribimos la estructura. El segundo es el panel de CSS, donde escribimos el estilo, y el tercero es el de JavaScript, otro lenguaje que no usaremos en este curso, así que por ahora lo ignoraremos.
>
> Y abajo está la vista previa, que muestra cómo se ve tu página y se actualiza sola mientras escribes.
>
> En la descripción de cada video encontrarás un enlace a un Pen ya preparado. Si quieres guardar tus cambios, el sitio puede pedirte crear una cuenta gratuita, pero para practicar por ahora no hace falta ese registro o esa cuenta."

### Bloque 5: Nuestro primer código HTML y CSS (03:14 – 04:58)

- **[En pantalla]:** Mostrar CodePen. Acercar el panel HTML y escribir el código progresivamente. Después, cambiar al panel CSS.
- **[Texto de apoyo visual]:**
    - `<h1> = Título principal`
    - `<p> = Párrafo`
    - `color = Propiedad CSS`
    - `tomato = Valor del color`
- **[Narración (Voz en off)]:**

> "Bien. Vamos a probar CodePen.
>
> En el panel HTML escribo un signo menor con la letra H y un número, por ejemplo, 1 y un signo mayor que. Después escribo mi primer sitio y para terminar la misma etiqueta, pero con una barra antes de la H. Mira, la vista previa ofrece un título.
>
> Ahora escribo un párrafo con la etiqueta P. El texto: 'Un sitio web es contenido HTML con estilo CSS'. Cierro la etiqueta de la misma manera que la anterior, pero esta vez con una P. Aparece abajo del título el nuevo párrafo.
>
> Hasta aquí solo ha sido HTML.
>
> Ahora vamos al panel de CSS. Escribo H1, abro llaves. Pongo color, dos puntos, tomato y cierro con un punto y coma.
>
> Tomato significa tomate en inglés y es un color rojizo. Mira, el título cambió de color solo. Eso es CSS en acción.
>
> No te preocupes por entender cada símbolo todavía. En los próximos videos lo veremos paso a paso."

### Bloque 6: Pausa interactiva y cierre (04:58 – 05:00)

- **[En pantalla]:** Mostrar el código CSS y resaltar la palabra `tomato`. Después, mostrar el mensaje: `¡PAUSA PARA PRACTICAR!`.
- **[Texto de apoyo visual]:**
    - `Cambia tomato por blue.`
    - `También puedes probar green o purple.`
- **[Narración (Voz en off)]:**

> "Bueno, ahora te toca a ti. Pausa el video, abre el enlace de la descripción y cambia la palabra tomato por blue, que es azul en inglés. Mira cómo cambia el título. Si quieres, prueba con green o purple.
>
> Y si algo sale mal, no te preocupes. Equivocarse es parte de aprender. En el próximo video crearás una página completa con estructura correcta. ¡Nos vemos!"

## Código de Referencia para la Lección

**Panel HTML:**

```html
<h1>Mi primer sitio</h1>
<p>Un sitio web es contenido (HTML) con estilo (CSS).</p>
```

**Panel CSS:**

```css
h1 {
  color: tomato;
}
```

## Actividad de Práctica

**Reto de la Lección 1 — Cambiando los colores de mi página**

**Objetivo:** Modificar el estilo del título utilizando diferentes valores de color en CSS.

1. Abre el enlace de CodePen que se encuentra en la descripción del video.
2. Busca la propiedad `color` dentro del panel CSS.
3. Cambia `tomato` por `blue`.
4. Comprueba cómo cambia el color del título en la vista previa.
5. Experimenta también con `green` o `purple`.

**Resultado esperado:** El estudiante reconoce la diferencia entre HTML y CSS, identifica los paneles principales de CodePen y modifica una propiedad CSS para cambiar la apariencia de su primera página web.
