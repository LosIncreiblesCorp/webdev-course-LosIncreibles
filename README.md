# Fundamentos de Desarrollo Web

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**Repositorio de código fuente**: [ENLACE_AL_REPOSITORIO](https://github.com/LosIncreiblesCorp/webdev-course-LosIncreibles.git)

## Secuencia de la lección


### Lección 1: ¿Qué es un sitio web? 
- **Duración:** 
- **Descripción**: Descubre de qué están hechos los sitios web y por qué HTML y CSS son sus componentes básicos.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_1)
- **Consejos clave**: Sitio web = Contenido (HTML) + Estilo (CSS).
- **Empieza a programar**: [Abrir CodePen](ENLACE_EDITOR_1)

### Lección 2: Tu primera página HTML 
- **Duración:**
- **Descripción**: Conoce la estructura básica de una página.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_2)
- **Consejos clave**: `<html>`, `<head>`, `<body>`.
- **Práctica**: [Clic para programar](ENLACE_EDITOR_2)

### Lección 3: Encabezados, párrafos y listas 
- **Duración:**
- **Descripción**: Aprende a organizar un texto con títulos, párrafos, texto resaltado y listas.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_3)
- **Consejos clave**: Usa un solo `<h1>` por página. `<ul>` es para viñetas, `<ol>` para números y `<li>` para cada elemento.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_3) 

### Lección 4: Imágenes y enlaces 
- **Duración:**
- **Descripción**: Inserta imágenes con texto alternativo y crea enlaces que llevan a otras páginas.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_4)
- **Consejos clave**: `<img src="..." alt="...">` no lleva etiqueta de cierre. Escribe siempre `alt`. Para abrir un enlace en otra pestaña usa `<a href="..." target="_blank">`.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_4) 

### Lección 5: Introducción a CSS 
- **Duración:**
- **Descripción**: Escribe tus primeras reglas CSS y aprende a elegir qué elementos cambiar.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_5)
- **Consejos clave**: `selector { propiedad: valor; }`. Elige por etiqueta (`h1`), por clase (`.destacado`) o por id (`#titulo`). Cada regla termina con `;`.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_5) 

### Lección 6: Colores, fuentes y bordes 
- **Duración:**
- **Descripción**: Dale estilo a una tarjeta de presentación con colores, tipos de letra, bordes y esquinas redondeadas.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_6)
- **Consejos clave**: `color` cambia el texto y `background-color` el fondo. En `font-family` escribe siempre una fuente de respaldo. `border`, `border-radius` y `padding` dan forma a la caja.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_6) 

### Lección 7: Centrar y organizar el contenido 
- **Duración:**
- **Descripción**: Entiende que todo elemento es una caja y aprende a centrar y ordenar cajas con flexbox.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_7)
- **Consejos clave**: `padding` es el espacio de adentro y `margin` el de afuera. `text-align: center` centra el texto. `max-width` junto con `margin: 20px auto` centra una caja. `display: flex` pone las cajas en fila.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_7) 

### Lección 8: Proyecto, página de perfil (parte 1: HTML) 
- **Duración:**
- **Descripción**: Planifica tu página de perfil y construye su estructura con HTML.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_8)
- **Consejos clave**: Haz un boceto antes de programar. Usa `<header>`, `<main>`, `<section>` y `<footer>`. La etiqueta `<link rel="stylesheet" href="style.css">` conecta el HTML con el CSS.
- **Proyecto**: [Abrir Replit](ENLACE_EDITOR_8) 

### Lección 9: Proyecto, página de perfil (parte 2: CSS) 
- **Duración:**
- **Descripción**: Dale estilo a tu página completa desde un archivo CSS y compártela.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_9)
- **Consejos clave**: El nombre del archivo en `<link>` debe ser idéntico a `style.css`. `header img` elige la imagen dentro del header. `border-radius: 50%` crea un círculo.
- **Proyecto final**: [Abrir Replit](ENLACE_EDITOR_9) 

### Lección 10: Errores comunes, buenas prácticas y próximos pasos 
- **Duración:**
- **Descripción**: Aprende a reconocer y corregir los cinco errores más comunes, y descubre cómo seguir aprendiendo.
- **Enlace**: [Ver la lección](ENLACE_YOUTUBE_10)
- **Consejos clave**: Los cinco errores son etiqueta sin cerrar, falta de `;`, imagen sin `alt`, confundir clase con id y escribir mal el nombre del archivo CSS. Prueba cambiando una sola cosa a la vez.
- **Práctica**: [Abrir CodePen](ENLACE_EDITOR_10) y corrige el código con errores.
- **Comparte tu trabajo**: [Envía tu creación](ENLACE_FORMULARIO) **¡Guarda y comparte!**
